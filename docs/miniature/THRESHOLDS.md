# 微缩重建阈值单一出处

代码常量：`services/reconstruction/app/miniature/contracts.py::THRESHOLDS`。
本文件的数字与代码逐项对应；改任何一项必须同时改这里并写明实测依据。

## 1. 输入准入（T-700067）

| 阈值 | 值 | 判据类型 | 实测依据 |
|---|---|---|---|
| `min_registered_ratio` | 0.60 | warn | 低于此值提示"存在大量未重叠视角或重复拍摄"。三场景实测（2026-11-12 复核）：c858acee 76/78 = 0.9744、f1014582 合并子模型后 102/104 = 0.9808（只读 `sparse/0` 是 60/104 = 0.5769）、llff_room 311/311 = 1.0。分母一律用 `processed/<id>/images` 文件数，不得用 `uploads`（见 `DATA-PROVENANCE.md`） |
| `min_images` | 20 | error | 少于 20 个注册相机无法支撑两墙一地的平面拟合。8d01db67 只有 3 张同哈希图 → `NO_SFM_BASELINE` |
| `min_lookdir_bins` | 6（/12 = 180°） | error | **准入硬门**。要看到两面墙，相机朝向必须覆盖至少半圈。70597d42 实测只占 2 桶 = 60° → `LOW_LOOKDIR_COVERAGE`，拒绝 |
| `report_azimuth_bins` | 6（/12 = 180°） | info（**不是硬门**） | 站位环绕只影响视差与遮挡补全质量。c858acee 站位仅 180°、朝向却 300°（手持原地转身），若把站位当硬门会误杀可用场景 |

> 站位与朝向必须分开：站立环绕（azimuth）决定三角化基线，转身朝向（lookdir）决定
> "能不能看到目标墙面"。把两者混成一个覆盖度指标，是上一轮误判的来源。

## 2. 结构推断（T-700068）

| 阈值 | 值 | 实测依据 |
|---|---|---|
| `min_floor_inlier_ratio` | 0.15 | 地板 RANSAC 内点占比下限。三场景实测 0.3026 / 0.3914 / 0.4352，留 2 倍余量 |
| `min_wall_points` | 200 | 单面墙的最少支撑点。低于 200 点时墙面法向估计不稳定（`extent_u` 抖动 > 10%） |
| `min_wall_extent_ratio` | 0.18 | 墙面沿另一水平轴的延展 / 该轴房间跨度。相对量，替代旧的固定 `min_wall_extent_nu=1.0`（固定 nu 阈值会让小房间筛光所有墙）；用于排除柱子、家具侧板、门框。每个被筛候选都会打日志，某轴筛空会抛 `NOT_ENOUGH_WALL_SUPPORT` |
| 墙厚带 `band` | `clip(0.06 × min(span_e1, span_e2, span_up), 0.08, 0.40)` | 按房间跨度自适应的厚度带：相对 6%、绝对下限 0.08 nu、上限 0.40 nu。固定值会在小房间过厚、大房间过薄 |
| 每侧峰数上限 | 8 | `_face_candidates` 的密度峰上限，超过 8 个峰说明该侧有大量家具干扰 |
| 保留墙数 | 每轴按墙面面积（`extent_u × extent_v`）取最大 | "两墙一地"的取向由面积投票决定，不写死坐标 |
| `max_wall_outside_ratio` | 0.25 | **仅诊断**，不参与拒绝。房间外侧常有走廊/邻室，把它当硬门会误杀 |

## 3. 实例识别（T-700068）

| 阈值 | 值 | 实测依据 |
|---|---|---|
| `voxel_nu`（聚类体素） | 0.05 | 5 cm 体素在 26 邻域下能把相邻家具分开、又不把单件家具打碎。0.04/0.06 敏感性实测见 `evidence_068.json::stability` |
| `min_points` | 80 | 少于 80 点的簇多为噪点或稀疏边角。配合 `min_unique_positions=20` 一起用 |
| `min_unique_positions` | 20 | 退化簇判据。f1014582 实测有一个 384 点的簇全部落在同一坐标（SfM 重复重建同一点），必须跳过并计数 |
| `ID_GRID_NU`（ID 量化粒度） | 0.6 | 三轴 5%/95% 分位中心量化。对比：0.25 nu + 均值质心 → 80% 采样下 ID 一致率仅 0.27；0.5 nu + AABB 极值中心 → 0.58；三轴 0.6 → 0.8125（c858acee 真视角对半切分）且无撞桶；0.8 会让 llff_room 掉到 0.75 |
| `partial` 判据 | `n_views < 3` | 只用可见视角数。**不能**用体素填充率：SfM 是表面采样，物体内部天然为空，实测填充率全部 < 3%，拿来判 partial 会 100% 命中 |
| `shell_ratio` | 0.5 | 单连通域占地板以上点云的比例，判"未分割的房间外壳"。**必须叠加尺寸条件**（至少两轴 > 0.5 × 房间跨度），否则稀疏场景里的单件大家具会被误判成外壳 |
| 置信度 | `0.40×sat(n/1500) + 0.60×sat(n_views/8)` | 证据量加权，非概率校准值。点数 40%、可见视角 60% |

## 4. 几何与纹理（T-700069 / T-700070）

| 阈值 | 值 | 实测依据 |
|---|---|---|
| 补洞半径 | 3（像素/体素） | r=8 会把接缝外的真实纹理一并抹掉并产生黄绿斑；r=3 只补观测空洞。上一轮实测对比记录在纹理卡证据里 |
| `min_surface_visibility` | 0.35 | 目标墙面/地板至少 35% 面积被某个视角看到；低于此视为观测不足，不进入烘焙 |
| 烘焙输入 | **渲染图，不是原照片** | 直接喂原照片会因相机位姿微小误差产生黄绿斑（通道错位）。必须用同一相机参数渲染出图再烘焙 |
| 视角文件映射 | 按 `name` 精确匹配 | 按 index 模糊匹配会在不同排序规则下错位 |
| 场景副本判定 | 按文件 MD5 | 同名不同目录不代表是不同数据 |

## 5. 维护规则

- 新增阈值必须同时出现在 `THRESHOLDS` 与本文件，并写"实测依据"。
- "仅诊断"的阈值必须在两处都标注，防止后续被误当硬门使用。
- 阈值改动必须重跑受影响的场景并更新证据文件，不得只改数字。
